# Mumit Studio — Creative Design & Web Solutions

A modern, responsive personal portfolio website for **Mumit Studio**, showcasing web development, graphic design, branding, digital marketing, skills, projects, and client testimonials.

## 🌐 About the Website

Mumit Studio is a creative design and web solutions portfolio built to present professional services and previous work in a clean, modern, and business-focused layout.

The website includes:

- Responsive hero section
- About Us section
- Skills & capabilities with progress bars
- Services showcase
- Portfolio / My Work section
- Client testimonials
- Call-to-action section
- Social media footer
- Responsive navigation
- Modern card-based UI
- Red, white, and dark professional color scheme

## ✨ Main Sections

### 🏠 Hero Section
Introduces Mumit Studio with a strong headline, short description, profile image, and call-to-action buttons.

### 👤 About Us
Provides an overview of the studio, experience, and expertise in graphic design, branding, website design, and web development.

### 💡 Skills & Capabilities
Displays core technical skills using visual progress bars, including:

- HTML5 & Bootstrap 5
- CSS3 & Custom Styling
- JavaScript ES6+
- UI/UX Layout Design

### 🛠️ Services
The website presents three main service categories:

- **Web Development**
- **Mobile Apps**
- **Digital Marketing**

### 🎨 My Work
A portfolio section highlighting branding and design projects such as:

- Dirty While Logo & Branding
- Delos Data Logo & Branding
- Green Blog Logo & Branding

### ⭐ Client Testimonials
A dedicated section for client feedback, ratings, and professional reviews.

### 📩 Let's Work Together
A call-to-action section encouraging visitors to get in touch for new projects and collaborations.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/mumit-studio.git
```

### 2. Open the Project

Open the project folder in **Visual Studio Code** or any preferred code editor.

### 3. Run the Website

Open `index.html` in your browser.

For the best development experience, use the **Live Server** extension in Visual Studio Code.
